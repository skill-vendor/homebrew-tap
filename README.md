# Homebrew Tap for skill-vendor

This tap contains Homebrew formulae for [skill-vendor](https://github.com/skill-vendor) tools.

## Installation

```bash
brew install skill-vendor/tap/skv
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [skv](https://github.com/skill-vendor/skv) | Repo-local, deterministic dependency management for agent skills |

## Updating

```bash
brew upgrade skv
```
